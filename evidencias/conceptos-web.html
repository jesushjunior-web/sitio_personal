Conceptos de la Web

Regresar al portafolio
ConceptoCaracterísticasEjemplos
Navegador webInterpreta HTML, CSS y JavaScript; permite acceder a contenidos mediante HTTP y HTTPS.Chrome, Firefox, Edge y Safari.
Página webDocumento individual con una dirección URL específica.Una noticia o una página de contacto.
Sitio webConjunto organizado de páginas relacionadas que comparten un dominio.Wikipedia o un sitio universitario.
Aplicación webSoftware interactivo que funciona mediante un navegador.Gmail, Google Docs y Canva.
Servidor webAlmacena, procesa y entrega contenidos a los navegadores.Apache, Nginx e IIS.
